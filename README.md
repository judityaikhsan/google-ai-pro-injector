# Gemini Injector by judith0x88

Chrome extension that injects Google One / AI Pro checkout offer tokens.

## Install (load unpacked)

1. Download this repo (Code -> Download ZIP) and extract it.
2. Open `chrome://extensions` and turn on Developer mode.
3. Click "Load unpacked" and pick this folder.
4. Sign in to the target Google account (U.S. region), then pick a layer in the extension popup.

## Safety

The popup shows a price guard: only continue when it says a free trial was detected and the total is $0.00. If no free trial is detected, do not subscribe.
